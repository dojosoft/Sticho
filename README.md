# Sticho

轻量级 Markdown / 纯文本 / 代码 / HTML 文档编辑器：像记事本一样打开 `.md` / `.txt` / 代码文件编辑，Markdown 即时
渲染（类 Typora），支持多标签页、命令面板、跨文件搜索；一键导出 Word / PDF / HTML / 纯文本 /
LaTeX / Epub，导入 Word / PDF / HTML 转 Markdown 继续编辑；内置代码高亮与代码小工具，并提供
WebDAV 云同步与本地版本历史。所有格式转换在本机完成，全程离线，适合涉密文档环境。

- 版本变化见 [CHANGELOG.md](./CHANGELOG.md)
- 本项目以 [MIT 许可证](./LICENSE) 开源
- 第三方许可证合规见 [THIRD_PARTY_LICENSES.md](./THIRD_PARTY_LICENSES.md)

## 安装

- 系统要求：Windows 10 1809 及以上（x64）
- 安装版：下载 `Sticho_x.x.x_x64-setup.exe` 双击安装（不需要管理员权限，`currentUser` 模式）
- 绿色版：下载 `Sticho_x.x.x_x64-portable.exe` 直接运行，无需安装
- 安装包内嵌 WebView2 引导器：系统缺少 WebView2 运行时时会自动引导安装（在线），Win10/11 一般已自带，无需额外操作

### 为什么双击安装包时会提示「未知发布者」

安装包没有购买代码签名证书（一张 Windows 代码签名证书需按年付费，个人项目通常不划算），因此
Windows SmartScreen 会显示「Windows 已保护你的电脑 / 未知发布者」。这代表**未签名**，不代表有病毒。
判断与继续安装的方式：

1. 点「更多信息」，确认发布者一栏显示为「未知发布者」而非某个陌生公司名；
2. 想核对文件完整性时，在项目目录执行 `npm run check-version` 打印安装包的 SHA256，与发布页给出的值比对；
3. 确认无误后点「仍要运行」即可正常安装。

安装包内嵌的 WebView2 引导器在系统缺失运行时时会联网下载，这是安装阶段唯一的网络请求。

## 功能

### 文档编辑与视图

| 功能 | 说明 |
|---|---|
| 三种文档模式 | Markdown（IR 即时渲染 / 所见即所得 / 分屏预览）、HTML（预览 / 源码）、纯文本 / 代码，可手动切换 |
| 多标签页 | 新建 / 关闭 / 关闭其它 / 前后切换，鼠标中键点击标签也能关闭 |
| 阅读 / 编辑模式 | 一键只读（状态栏开关），打开文档的初始模式可在设置里指定 |
| 大文档分节阅读 | 超过约 256KB 的文档自动进入分节只读视图（滚动虚拟化 + 行号 + 查找），避免几 MB 文档卡死界面 |
| 编辑器显示 | 排版工具栏（仅 Markdown）、行号（纯文本 / Markdown 分屏 / HTML 源码）、状态栏字数统计与保存状态 |
| 中英文自动空格 | 预览与导出统一按 Lute 规则在中英文之间补空格，导出不再与预览不一致 |

### 写作与格式

| 功能 | 说明 |
|---|---|
| 段落 | 标题 1~6 级 / 正文、有序 / 无序 / 任务列表、缩进增减、引用、分隔线 |
| 表格 | 插入表格，支持整列左 / 中 / 右对齐 |
| 行内格式 | 加粗、斜体、删除线、行内代码、链接、表情 |
| 代码块 | 插入代码块并可选择语言 |
| 公式与图表 | 行间公式（Math）、Mermaid 图，预览与导出均参与渲染 |
| 插入图片 | 本地图片写入文档同级的 assets 目录（不内联 base64），正文引用相对路径 |
| 快捷操作 | 排版工具栏 + 菜单 + 快捷键三套入口，功能一致 |

### 查找与导航

| 功能 | 说明 |
|---|---|
| 查找替换 | Ctrl+F / Ctrl+H，支持区分大小写、全词匹配、正则 |
| 命令面板 | Ctrl+P 搜索并执行菜单中的任意命令（含最近文件、文件历史等动态项） |
| 跨文件搜索 | 侧边栏「搜索」标签，在当前文件夹内全文查找（字面量 / 正则），最多 5000 个文件、500 条命中 |
| 侧边栏面板 | 文件树、文档大纲、文件属性、搜索、云端文件夹，各自可单独开关 |
| 文件属性 | 查看当前文档的路径、大小、编码、统计等信息 |

### 导入、导出与打印

| 功能 | 说明 |
|---|---|
| 导出 Word | `.docx`：标题层级 / 列表 / 表格 / 代码块 / 引用；正文图片真实嵌入，Mermaid 图转为图片；未能嵌入的图片回落为占位文字并给出汇总说明 |
| 导出 PDF | `.pdf`：A4 版式，中文无方块字，页眉显示文档名、页脚显示「第 X / Y 页」，静默导出无打印对话框 |
| 导出 HTML | 单文件、样式内嵌、浏览器直接打开，图片以 data URI 自包含；HTML 文档导出时按源码原样写出 |
| 导出纯文本 | `.txt` |
| 导出 LaTeX / Epub | `.tex` / `.epub`，经 Pandoc 转换（首次使用时引导下载） |
| 打印 | 走系统打印对话框（WebView2 自带预览），只打印正文，不带工具栏 / 侧边栏 |
| 导入 Word | `.docx` → Pandoc → GFM Markdown，图片内联 |
| 导入 PDF | 文字版 PDF 提取文本与标题层级，尽力转换 |
| 导入 HTML | `.html` 转 Markdown 继续编辑（turndown + GFM，支持表格 / 删除线 / 任务列表） |
| 拖拽打开 | md / html / docx / pdf 拖入窗口直接打开或导入 |
| 另存与编码 | 导出时可另选路径；保存按当前编码写回 |

### 代码文件与代码工具

| 功能 | 说明 |
|---|---|
| 代码高亮 | 代码文件白名单（含无扩展名文件与 `.txt`），按扩展名自动匹配 20 种语言 / 方言：Python、Batch、PowerShell、Shell、JavaScript、JSX、TypeScript、TSX、JSON、XML、HTML、CSS、YAML、TOML、Properties(ini/cfg/conf/env)、SQL、C/C++、Rust、Go、Java；可在「视图 → 语法高亮语言」手动指定或选纯文本 |
| 超大代码文件 | ≥ 2MB（约 5 万行）改用只读分节纯文本，牺牲高亮换取可用性 |
| 美化 / 压缩 | JSON、CSS、JS 的美化与压缩（JS 为**安全子集**：只重排缩进、只删空行，绝不合并行） |
| 代码小工具 | Base64 编解码、进制转换（2 / 8 / 10 / 16，支持按前缀自动识别）、GUID 生成、时间戳（本地 / 日期 / 时间 / ISO 8601 / Unix 秒 / Unix 毫秒），结果可一键替换选中或插入光标处 |

### 编码

- 打开时自动识别编码，可在状态栏或菜单手动切换，并按所选编码保存
- 支持：UTF-8、UTF-8 (with BOM)、UTF-16 LE / BE、GBK / GB18030、Big5、Shift_JIS、EUC-KR、Windows-1252

### 云端同步（WebDAV）

| 功能 | 说明 |
|---|---|
| 连接配置 | 服务器 URL / 用户名 / 密码 / 远端根目录，可「测试连接」，连通后才允许启用 |
| 云端浏览 | 侧边栏「云端文件夹」浏览远端目录，云端文档打开为未命名文档，用「另存」保留本地副本 |
| 冲突处理 | 云端文件被其它设备改动时：默认「保留冲突副本」（在同目录另存一份，绝不覆盖对方），也可选「覆盖云端副本」 |

### 历史与恢复

| 功能 | 说明 |
|---|---|
| 本地版本历史 | 每次覆盖保存前自动留档，可从「文件 → 文件历史」就地回滚；每文件保留数量在设置里选（5 / 10 / 20 / 30 / 50 / 100 / 200） |
| 恢复草稿 | 开启后按设定间隔（默认每 1 分钟，可选 30 秒 ~ 30 分钟）自动保存恢复草稿，崩溃或异常退出后下次启动可恢复；同时每 5 秒检测外部文件改动 |
| 恢复中心 | 「文件 → 恢复中心…」统一浏览恢复草稿与全部文档的本地版本历史，支持预览 / 恢复 / 另存 / 删除 |

### 外观与阅读

| 功能 | 说明 |

### 界面语言

- 内置简体中文与 English 两套词表；语言包以**英文原文为键、译文为值**，未翻译的键自动回落英文，不会显示空白
- 语言包放在配置目录的 `locales/` 下（`.json`），文件名主干即语言 id（如 `fr-FR.json`），重启后在「设置 → 语言」中选用
- 首次运行引导即可选择界面语言（默认中文），设置里可随时切换，**切换后立即生效**（含编辑器工具栏提示），无需重启
- 界面任何位置兜底为英文：语言包覆盖不到的地方一律显示英文

## 自定义：语言包 / 主题 / 字体

首次运行会把说明文件与示例释放到配置目录下的 `locales/`、`themes/`、`fonts/`，照着改即可：

- **语言包**（`locales/*.json`，UTF-8）：`{ "_label": "Français", "File": "Fichier", "Save": "Enregistrer" }`；`_label` 为下拉框显示名，可省略
- **主题**（`themes/*.css`）：选择器直接写界面与编辑器的类名（如 `.vditor-reset`），叠加在当前明 / 暗档位之上
- **字体**（`fonts/*.ttf|otf|woff|woff2`）：字体名即文件名主干，随后在「设置 → 阅读排版 → 字体」中选用

自带语言包（`zh-CN.json` / `en-US.json`）随程序版本管理：目录中的版本落后于程序内置版本时会自动覆盖更新，缺失时会补充释放；主题 / 字体 / 说明文件只在缺失时释放，改过或删掉的不会被写回。

## 已知限制

- **文件大小上限**：文本文件 10MB，PDF 导入 50MB，单张图片 20MB（插入时前端软限制 5MB）
- **大文档**：超过约 256KB 的文档进入分节只读阅读模式（内容随滚动补齐）
- **超大代码文件**：≥ 2MB（约 5 万行）转为只读分节纯文本，无语法高亮
- **PDF 导入为尽力转换**：仅支持文字版 PDF；扫描件（图片型）会明确提示无法提取；表格、多栏排版、代码块退化为纯文本，需人工校正
- **Pandoc 依赖**：导入 Word 与导出 LaTeX / Epub 需要 Pandoc（GPL-2.0），首次使用时按需下载到用户数据目录（约 35MB），不随安装包分发
- **JS 美化 / 压缩为安全子集**：只重排缩进、只删空行，不合并行（避免破坏 ASI、模板串与正则字面量）
- **WebDAV**：不支持自签名证书（请用公共 CA，或仅在可信内网使用明文 http）；密码经 Windows DPAPI 加密后保存在本机的 `secrets.json`（绑定当前 Windows 用户，换用户或换机器都无法解密），但明文 http 下凭据仍可能在传输途中被截获，建议优先用 https；同步失败不影响本地保存

## 隐私与安全

- 程序本体不主动联网，仅在三种情况下发起网络请求：① 安装阶段系统缺少 WebView2 运行时；② 首次使用导入 Word / 导出 LaTeX / Epub 时按需下载 Pandoc；③ 你主动配置并启用的 WebDAV 云同步
- 无数据上报、无统计埋点
- 文档中引用的远程图片 / 媒体默认不加载（预览显示占位提示），外链需手动点击后在系统浏览器打开
- 只在用户显式选择的路径读写文件
- 诊断报告导出前会剔除密码等敏感字段

## 开发

环境要求：Node.js 20+、Rust stable 工具链（`rustup` + `cargo`）、Windows 10 1809+ 与 WebView2 运行时。
NSIS 由 Tauri 自动准备，无需手工安装。

```powershell
npm install
npm run tauri dev        # 开发调试
npm run tauri build      # 打包 NSIS 安装包
npm run release          # 一键发布：构建 → 归档到 release/ → SHA256 → 复制绿色版到桌面
npm run check-version    # 校验三处版本号一致，并打印安装包 SHA256
npm run check            # svelte-check 类型检查
npm run lint             # ESLint
npm run test             # Vitest 单元测试
npm run i18n-missing     # 列出未收录英文的界面文案
```

Vditor 的运行时资源（公式 / 图表 / 代码高亮配色 / 表情图片等，约 12MB）不入库：`predev` / `prebuild`
会先跑 `scripts/sync-vditor-assets.mjs`，从 `node_modules/vditor` 同步到 `public/vditor/`，所以
`npm run tauri build` 开箱可用，不必手工拷贝。

提交前请让下面这些门禁全部通过（与 CI 的 [.github/workflows/ci.yml](./.github/workflows/ci.yml) 一致）：
`check-version`、`test`、`check`、`lint`、`i18n-missing`、`build`，以及
`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test --lib`。

技术栈：Tauri 2（Rust）+ Svelte 5 + Vite + Vditor 3 + CodeMirror 6 + markdown-it + TypeScript strict。
